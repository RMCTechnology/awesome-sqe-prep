# Contributing

Thanks for helping curate this list. Please follow these conventions so the list stays useful and easy to scan.

## What belongs here

- Resources that are **directly useful** to candidates preparing for the qualification.
- Free resources are prioritised. Paid resources are welcome if they are widely regarded as worthwhile — note the price model in the description.
- Official material from the awarding body always belongs.

## What does not belong

- Affiliate links, tracking parameters, or referral codes.
- Dead or paywalled-without-disclosure links.
- Self-promotion without disclosure. If you maintain a tool listed here, say so in the PR.
- Duplicate listings of the same resource across sections.

## Format

- One resource per line.
- Use the format: `- [Name](url) — Description.`
- Description starts with a capital letter and ends with a full stop.
- One sentence. Two if absolutely necessary.
- Alphabetical order within each section, ignoring leading articles (*The*, *A*, *An*).
- Use `—` (em dash) between the link and the description.

## PR checklist

Before submitting:

- [ ] Resource fits the scope of this list.
- [ ] Link works and points to a stable URL.
- [ ] No tracking or affiliate parameters in the URL.
- [ ] Description follows the format above.
- [ ] Entry is in alphabetical order within its section.
- [ ] You have disclosed any affiliation with the resource.

## Adding a new section

If your contribution does not fit any existing section, open an issue first to discuss whether a new section is warranted, or whether it belongs in a different awesome list.
